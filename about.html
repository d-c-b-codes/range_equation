this is a coding project i made in june 2026 for a 200-level (calc-based) phys series final project

this project applies the physics of the range equation:

R = v02sin2θ / g

i also needed to use the other kinetamtic equations (namely the two below) to get the animations to work properly:

x = x0 + vx0t (without acceleration)

y = y0 + vy0t + 1/2at2 (with acceleration)

if you're savvy, you can find representations of each of those in the source code
